# Mini Orders Dashboard

A simple React dashboard that displays orders in a table view with search, pagination, editable status, and an order detail drawer.

## Prerequisites

- Node.js v18.19.1 or compatible
- npm 9.2.0 or compatible

## Install

```bash
npm install
```

## Start the app

```bash
npm run dev
```

This starts the Vite dev server and a mock JSON Server backend concurrently.
